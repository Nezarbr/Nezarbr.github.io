# nezarbr.github.io

Portfolio of Nezar Boujida, Data Scientist: https://nezarbr.github.io

Built with [Astro](https://astro.build) on the [AstroWind](https://github.com/arthelokyo/astrowind) template (MIT, see `LICENSE.md`).

```bash
npm ci
npm run dev     # local preview at http://localhost:4321
npm run build   # static site in dist/
```

Every push to `main` is checked, built and deployed to GitHub Pages by `.github/workflows/deploy.yml`.
